✦Fortune's WeaveGrowth Calculator
How it works
  • Total growth = character + class + mount (Bond 5), plus Signs of Growth for Mu.
  • Planner: lay out class changes by level, see average stat gains, and type in your unit's current stats to project where they end up. Auto-build picks classes for the stats you choose.
  • Class Finder ranks every class for a character; Compare puts up to 4 characters side by side.
  • Every view has a share link. Plans and recruitment ticks are also saved in this browser.
  • Spoilers is off by default: Divine classes, Part III mounts and late-game units stay hidden.
  • Base stats and stat caps aren't published yet, so neither is applied.
  • On a phone, use Add to Home Screen to open it like an app.
